## Hipótesis del Proyecto

> Al implementar estructuras de haya en la programación de rutas en redes, se logrará una búsqueda de caminos óptimos con menor tiempo de respuesta y un uso más eficiente del ancho de banda, en comparación con algoritmos de recorrido secuencial.

### Explicación
La estructura de haya organiza la información de forma jerárquica, permitiendo reducir la cantidad de comparaciones necesarias para localizar la mejor ruta entre nodos. Esta organización mejora el rendimiento especialmente cuando la red aumenta su tamaño y cantidad de equipos conectados.

### Objetivo
Verificar que el uso de recorridos basados en hayas optimiza la velocidad y eficiencia en la determinación de rutas dentro de una red programada.
